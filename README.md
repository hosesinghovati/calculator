# Calculator 🧮

A simple and responsive calculator built with HTML, CSS, and JavaScript.

## About the Project

This is a beginner-friendly calculator project created to practice front-end web development.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear all (AC)
- Delete last character (DEL)
- Decimal number support
- Keyboard support
- Error handling for division by zero

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator!
